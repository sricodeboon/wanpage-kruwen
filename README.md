# วันเพจ (ระบบใหม่)

เว็บ: https://sricodeboon.github.io/wanpage-kruwen/ · ระบบเดิม (Google Sheets / Apps Script) เก็บไว้ที่ branch `legacy-v1`

เว็บแอปสร้างภาพรายงานหน้าเดียวแบบ "วันเพจ" แล้วส่งเข้า LINE มี 2 แบบ
- **ครูเวร** — ตรา · แถบหัวเรื่อง · โรงเรียน/ที่อยู่ · รูป 4 ภาพพร้อมป้ายชื่อ · กล่องครูเวร (ชื่อ + เบอร์ สูงสุด 3 คน)
- **อาหารกลางวัน** — แบบเดียวกัน แต่กล่องล่างเป็น เมนูอาหาร + ข้อความ และป้ายชื่อรูปดึงจากเมนู
- **หน้าแถว** — หนังสือรายงาน: เรียน… / วันที่ / ข้าฯ (ผู้รายงาน) ขอรายงานการ ปบ. ดังนี้ / ข้อ ๑ ๒ … / จึงเรียนมาเพื่อโปรดทราบ + รูป 4 ภาพ (ใช้ `renderLunch` กับ `kind: 'assembly'`)

เครื่องวาดภาพ (`js/engine/`) พื้นหลัง 68 แบบ (`data/templates.json`, `assets/bg/`) ตรา และฟอนต์ ยกมาจาก
`sricodeboon/wanpage-kruwen` — ภาพครูเวรออกมาเหมือนเดิม ส่วนที่เพิ่มคือ `lunchLayout()` ใน `layout.js` และ `drawLunch()` ใน `render.js`

## หน้าจอ (แตะที่ภาพ)
- ภาพรายงานคือตัวแก้ไข: แตะช่องรูป กล่องครูเวร เมนู ข้อความ "เรียน…" หัวเรื่อง ตรา/ชื่อโรงเรียน เพื่อแก้ตรงนั้น
- ช่องที่ยังขาดกะพริบ · มือถือ = แผงเลื่อนขึ้นจากล่าง · คอม = แผงด้านขวา ภาพยังเห็นสด
- ตำแหน่งจุดแตะมาจากเครื่องวาด: `computeLayout()` (ครูเวร) และค่าที่ `renderLunch()` คืนกลับ (อาหารกลางวัน)

## คุยกับครูแจ็ก
- ปุ่ม "ถามครูแจ็ก" ในกล่องข้อความของมาสคอต → หน้าแชท (`js/chat.js`)
- ถาม-ตอบแบบออฟไลน์ จับคำสำคัญ (ไม่ใช้ AI ไม่ต้องใช้เน็ต) และมีปุ่ม "ทำให้เลย" เช่น เปิดรายชื่อครู เลือกรูป
- ทำได้: บอกขั้นต่อไปจากสิ่งที่ยังขาด · ถามเบอร์ครูจากชื่อ/นามสกุล แล้วเลือกเป็นครูเวร · เปลี่ยนวันที่จากข้อความ ("เมื่อวาน", "5 พ.ย.", "วันที่ 3")
- เพิ่มคำถามใหม่: เพิ่มรายการใน `INTENTS` (kw = คำสำคัญ, r = คำตอบ)

## ต่างจากระบบเดิม
- เว็บนิ่งล้วน ไม่ต้อง build / ไม่ใช้ Google Sheets / ไม่ใช้ Apps Script
- รายชื่อโรงเรียน ครู ป้ายชื่อรูป อยู่ใน `data/schools.json` (แก้ไฟล์เดียว) — มีเบอร์โทรครูมาให้แล้ว เพิ่มครู/แก้เบอร์เองในแอปได้ (จำไว้ในเครื่อง)
- โรงเรียนอื่นกรอกเองได้ (ชื่อ ที่อยู่ ตรา จังหวัด)
- รูปที่เลือกเก็บใน IndexedDB ของเครื่อง สลับไปแอปอื่นแล้วกลับมาไม่หาย
- รองรับมือถือ/แท็บเล็ต/คอม · โหมดมืด · ลดการเคลื่อนไหวตามเครื่อง

```
python tests/serve.py        # ปิดแคช แก้ไฟล์แล้วรีเฟรชเห็นผลทันที
```
แล้วเปิด http://127.0.0.1:8765/ — ปุ่ม "ส่งเข้า LINE" (Web Share) ใช้ได้จริงเมื่ออยู่บน https เช่น GitHub Pages

## แก้ข้อมูล
- เพิ่มโรงเรียน: แถวใน `data/schools.json` → `schools` + ไฟล์ตราใน `assets/logos/`
- เพิ่มครู: `teachersBySchool.<school_id>` (`display_name`, `phone` แบบ 0xx-xxx-xxxx) — ชื่อ+เบอร์ทั้ง 125 คนดึงมาจากแท็บ `teachers` ของ Google Sheet ระบบเดิม (11 พ.ย. 2569)
- เบอร์ที่ครูแก้ในแอปเก็บในเครื่อง (`settings.phones`) และใช้แทนเบอร์ในไฟล์
- ในแอป: เพิ่มครูเองได้ · แตะดินสอเพื่อแก้ชื่อ (ชื่อจากไฟล์เก็บเป็น `settings.names[school_id][ชื่อเดิม]`, ชื่อที่เพิ่มเองลบได้) — เก็บในเครื่องเท่านั้น ถ้าจะให้ทุกเครื่องเห็นต้องแก้ `data/schools.json`
- ป้ายชื่อรูปครูเวร: `labels` (icon = building field farm canteen classroom flag walkway library kitchen toilet fence camera)
