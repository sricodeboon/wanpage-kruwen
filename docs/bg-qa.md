### การปรับ `landmark_top_y` (ข้อเดียวที่เบี่ยงจาก spec)
spec ให้ใช้ "std ต่อแถว > 20" แต่วัดจริงไม่ไวพอ: np-01 ได้ 979 (ยอดจริง ~890), np-02 ได้ 966 ทั้งที่ spec ระบุยอดจริง ≈ 795 ที่ไม่ผ่าน → ตัวตรวจจะปล่อยแบบที่ไม่ผ่านให้ผ่าน จึงปรับเป็น
1. มองเฉพาะกรอบ x 230–800 (จุดเด่นหลัก)
2. ตัดการไล่โทนเรียบออก (ลบค่าเฉลี่ยเลื่อน ±20 px ต่อแถว) แล้วใช้ std ที่เหลือ **> 3**
3. เริ่มสแกนที่ y = 25% (384) เพราะลายขอบฟ้า/ของประดับบนของ np-01 ลงมาถึง ~y 300
4. เกณฑ์ผ่านคือ ≥ **895** (spec 904 เผื่อความคลาดเคลื่อนการวัด 9 px — np-01 วัดได้ 898 ผ่าน "พอดี", np-02 วัดได้ 798 ตรงกับค่า 795 ที่ spec ระบุ)

### ขั้นตอนต่อภาพ
1. ต้นฉบับ `assets/backgrounds/v3/raw/<id>.png` (ไม่ commit)
2. `python3 tools/fit-bg.py assets/backgrounds/v3/raw/<id>.png assets/backgrounds/v3/<id>.png --scene <scene>`
   ระบุ `--scene` = นโยบายซ่อมภาพอัตโนมัติ v3 (`docs/design/templates-v3.md` §8) · **ไม่ระบุ `--scene` = ทางเดิมของชุด v2 ผลเหมือนเดิมทุกบิต**
   (ตรวจแล้ว 24 ต.ค. 69: v2/np-01 sha1 `f763b5ad…`, np-02 `c5917ef4…`, sn-04 `befb9a0d…`, mdh-01 `9f3902c9…` ก่อน/หลังแก้ตรงกัน)
   ลำดับ: (0) ล้างเขียว §8.4 (+ ใบไม้ olive ในลายมุม hue 34–60 V < 0.62 — ใบดาวเรือง np-13) → (1) ย่อฉาก uniform → (2) เลื่อนเฉพาะฉาก → (3) feather/เติมฟ้า/ม่านโซนตรา → (4) หรี่คลื่น → (5) veil เดิม
   side: ยอดจริง = ส่วนบนสุดของวัตถุที่ต่อลงถึงพื้น (เมฆ/ดอกไม้มุมไม่นับ) · ขอบแข็ง = max(ตัวตรวจเส้นตั้งยาว ≥ 60 px, ค่าที่ Fable วัดด้วยตา `HARD_HINTS`)
   ค้น s จาก 1 ลงทีละ 0.01 ถึง 0.70 (ยอดหลังย่อ ≥ 420) + เลื่อนฉาก ≤ 40 ให้ขอบแข็ง ≤ x 352 (L) แล้วตรวจ §8.1 ข้อ 4 (แถว std > 3 ใน x 370–400 ≤ 15%) + พอร์ต check-bg ทุกข้อ
   วางเฉพาะ "ตัวฉาก" (ใต้เส้นขอบฟ้าของวัตถุ) บนฟ้าที่เติม · ม่าน feather = สีแถบไกลต่อแถว ไล่จากสีฟ้าขอบคอลัมน์สถานที่ · ดอกไม้มุมล่างฝั่งรูปไม่ถูกม่าน · ใต้สันคลื่นใช้คลื่นเดิม
   bottom: ขาด ≤ 24 ยืดฟ้าเดิม · เกินนั้นย่อแถบฉากเต็มกว้าง (s ≥ 0.68) เลือก s ใหญ่สุดที่ landmark ≥ 900 · ช่องข้าง mirror · ไล่ฟ้าบนต่อเนื่องถึงแถวบนของฉากที่ย่อ · ม่านโซนตราทรงรี (k ≤ 0.7)
   **exit 1 และไม่บันทึกผล** เมื่อซ่อมไม่ได้ภายใต้เพดาน → สร้างภาพใหม่ (พรอมต์สำรองต่อภาพอยู่ใน templates-v3.md §8.5)
3. `node tools/check-bg.mjs --id <id>` (ไม่ระบุไฟล์ = `v3/<id>.png` ถ้ามี ไม่งั้น `v3/raw/<id>.png`; แม่แบบเดิม = `site/<file>`; ยังไม่มีภาพ → บอกพาธที่ต้องมี exit 2)
4. `node tools/make-bg.mjs assets/backgrounds/v3/<id>.png <id>`
5. ตั้ง `landmark`/`band` จริงใน templates.json (แก้ด้วยมือ) → `node tools/goldens.mjs --include-inactive --only <id>` ดูพรีวิว → เปิด `active: true`
   (รันแบบ `--only`/`--include-inactive` เขียนหน้าดูที่ `tests/golden/actual/index.html` ไม่ทับ `docs/goldens/index.html` — ก่อน commit รัน `npm run goldens` เต็มอีกรอบ)
