### 1.2 สามฉาก (`scene`)

ข้อความ (ตรา/หัวเรื่อง/โรงเรียน/ที่อยู่/ครูเวร) **คงกลางทุกฉาก** — เหตุผล: (ก) ส่วนหัวอยู่เหนือ y 400 ซึ่งภาพด้านข้างถูกสั่งให้ว่างทั้งความกว้างอยู่แล้ว (ข) กล่องครูเวรอยู่บนแถบคลื่นเต็มความกว้าง (ค) ไม่ต้องแตะ dutyLayout/drawTitle เลย ความเสี่ยงต่อ golden เดิม = 0 (ง) เอกลักษณ์ของแบบมาจากคอลัมน์สถานที่ที่สูงเต็มด้านอยู่แล้ว ไม่ต้องย้ายข้อความให้อ่านยาก

### 1.3 เรขาคณิตคอลัมน์แคบ (W = 554, g = 20.5, H = limit − top; dy 0 → H = 1007, dy 54 → 953)
**C1+2+1** (รูปหลักบน / คู่กลาง / กว้างล่าง) — a = H − 2g
- main: x0, top, 554 × round(a·0.38) (dy0 → 367 สัดส่วน 1.51:1)
- pair: 2 ช่อง กว้าง (554−20.5)/2 = **266.75** (≥ minSmallW 260 ✓) สูง round(a·0.27) (→ 261)
- wide: 554 × (a − main − pair) (→ 338; พื้นที่ 187k < main 203k ✓)
- บังคับขั้นต่ำ: main ≥ 240, pair/wide ≥ 170; ถ้าไม่พอ push error เหมือน rows2
- ลำดับช่อง: 0 = main, 1–2 = pair ซ้าย→ขวา, 3 = wide

**C2+2** (ตาราง 2×2 ในคอลัมน์) — rows = (H − g)/2 แต่ **จำกัดแถวละไม่เกิน 420** (กันรูปเป็นแนวตั้งผิดธรรมชาติ) แล้วจัดชิดบน; ช่องกว้าง 266.75; ช่อง 0 = บนซ้าย (พื้นที่เท่ากันทุกช่อง ผ่านเงื่อนไข "ไม่ใหญ่กว่ารูปหลัก" ได้เพราะใช้ >)
- dy0: H = 1007 → row = min(493, 420) = 420 → ใช้สูง 860.5 ที่เหลือใต้รูป (~146) ปล่อยว่างให้พื้นหลังหายใจ

ป้ายชื่อรูป: กว้าง 554 < MAIN_LABEL_MIN_W 600 → ใช้ป้ายปกติทุกช่อง (ไม่ต้องแก้)

### 1.4 สกีมา templates.json (schemaVersion คง 1 — ฟิลด์ใหม่เป็น optional ทั้งหมด)
```jsonc
// common (เพิ่ม)
"side": { "colW": 554, "gutter": 24, "landmark": { "y": 400, "h": 980, "w": 400 },
          "bandGap": 16, "maxRowC2x2": 420, "ratioC1": { "main": 0.38, "pair": 0.27 } }

// แม่แบบใหม่ (ตัวอย่าง)
{ "id": "np-11", "version": 1, "active": true, "name": "พระธาตุนคร ม่วงทอง",
  "province": "np", "scene": "side-L", "photo_layout": "C1+2+1",
  "file": "assets/bg/np-11.v1.webp", "thumb": "assets/bg/thumb/np-11.v1.webp",
  "palette": { ... }, 
  "landmark": { "x": 0, "y": 400, "w": 400, "h": 980, "note": "พระธาตุนคร" },   // คอลัมน์ซ้าย
  "band": { "top_y": 1380 }, "overrides": {}, "approvedAt": null }
```
- `scene` ไม่มี → `"bottom"` → โค้ดเดินทางเดิมทุกบรรทัด
- side-R: `landmark.x = 1024 − 400 = 624`
- `overrides.side` ใช้ปรับคอลัมน์เป็นรายแบบได้ (เช่น ภาพที่สถานที่กินกว้างถึง 420 → `landmark.w 420`, colW 534)
- `mergeTemplate`: เพิ่ม `'scene'` ใน KEEP และ default `out.scene = tpl.scene || 'bottom'`

### 1.5 กฎใน validateTemplate (เพิ่มเฉพาะเมื่อ scene ≠ bottom)
0. **ต้องแยกทางก่อน**: กฎเดิม `q.y+q.h+landmarkGap > landmark.y` (บรรทัด ~418) และ `limit = landmark.y − landmarkGap` ใน photoGeometry ใช้ไม่ได้กับ side (landmark.y = 400 อยู่เหนือรูป) → ครอบด้วย `if (r.scene === 'bottom')` แล้วใช้กฎ 2–3 ด้านล่างแทน; กฎ 4 ใช้ landmark rect ของ side เท่านั้น
1. `photo_layout` ต้องเป็น C-layout เมื่อ side และ **ห้าม** เป็น C-layout เมื่อ bottom
2. ทุกช่องรูปอยู่ในคอลัมน์: side-L → x ≥ landmark.x+landmark.w+gutter; side-R → x+w ≤ landmark.x − gutter
3. ทุกช่องรูป y+h+bandGap ≤ band.top_y
4. landmark.y ≥ 394 (ใต้ที่อยู่ 2 บรรทัด) และ landmark ต้องไม่ทับ title/school/address rect
5. ตรวจ dy 0 และ dy 54 เหมือนเดิม

### 2.2 fit-bg.py — โหมด side
- ไม่ยืดท้องฟ้าแนวตั้ง (shift_down) — ใช้ไม่ได้กับคอลัมน์
- ใหม่ `veil_column(img, side)`: ม่านสว่างเฉพาะสี่เหลี่ยมโซนรูป + header zone ขอบนุ่ม 40 px (ไม่ทับคอลัมน์สถานที่)
- ใหม่ `shift_x(img, d)`: ถ้า gutter_clean ไม่ผ่านเพราะสถานที่ล้ำ ≤ 40 px → เลื่อนภาพแนวนอนออกไปด้านขอบ d px แล้วต่อขอบด้วยพิกเซลริม (edge-extend) ; ล้ำ > 40 → สร้างใหม่
- darken_band เหมือนเดิม (แถบล่างเต็มความกว้าง)
- make-bg.mjs ไม่ต้องแก้ (ครอป 2:3 กลาง + webp) — แต่ **ห้ามครอปแนวนอน** ถ้าต้นฉบับ Gemini 1696×2528 ต้องยืนยันว่าครอป 1 px ไม่กินคอลัมน์ (คลาด 0.63% = ~5 px ปลอดภัย)

### 2.3 เกณฑ์ตรวจด้วยตา (ครู/Fable) ก่อน approve

### 8.1 ฉาก side — ย่อฉากในคอลัมน์ (uniform, ยึดมุมล่างฝั่งขอบ) + feather เข้าพื้นสว่าง
1. **ขอบเขตฉาก**: กล่อง x 0–470 (L) / 554–1024 (R), y จาก `landmark_top − 30` ถึง 1536 (รวมแถบคลื่น — แถบจะถูกแปะกลับทีหลัง)
2. **ย่อ** ด้วยอัตรา s เดียวกันทั้ง x/y ยึดมุม (0, 1536) L / (1024, 1536) R — ฐานยังนั่งบนแถบคลื่นเท่าเดิม เลือก s จาก 2 เงื่อนไข ต่ำกว่าเพดาน **s ≥ 0.70** เท่านั้น (ต่ำกว่า = สร้างใหม่):
   - ยอด: `1380 − s·(1380 − tip_y) ≥ 420` (เกณฑ์ 390 + เผื่อวัด 30)
   - ความกว้าง: **เงาสถานที่ (ขอบแข็ง)** หลังย่อ+เลื่อนต้องอยู่ใน x ≤ 370 (L) / x ≥ 654 (R) — ระยะ 30 px ก่อนแถบ gutter เพื่อให้ ramp ม่านไม่กินตัวสถานที่
   - พื้นที่ว่างที่เกิดจากการย่อ: แถบบน (y < ขอบบนฉากใหม่) และแถบด้านใน (x ระหว่างขอบฉากใหม่กับ 470/554) **ลบฉากเดิมก่อน** ด้วยไล่สีฟ้าเดิม: ต่อแถวใช้สีจากแถบไกลฝั่งรูป (L x 860–960 / R x 60–160) ผสมกับสีแถว `landmark_top − 60` ของคอลัมน์เอง (ไล่เชิงเส้นตามแนวดิ่ง) แล้วค่อยวางฉากที่ย่อทับ ขอบวางมีขนนุ่ม 24 px
3. **เลื่อน** `shift_x` ≤ 40 เหมือนเดิม (edge-extend) ใช้เฉพาะเศษที่เหลือหลังย่อ
4. **ม่านจาง (feather veil) แทนการ exit 1**: แทนที่พิกเซลด้วย "พื้นสว่างสังเคราะห์" (สีต่อแถวจากแถบไกลเฉพาะแถวที่ std ≤ 3, แถวอื่น interpolate) ด้วย alpha **1.0** ในโซน x ≥ 400 (L) / x ≤ 624 (R), ramp smoothstep เป็นหมอกขอบโค้ง (24 ต.ค. 69 — เดิม 30 px ตรงที่ x 370→400 เห็นเป็นเส้นตั้งในรายงาน np-20): เริ่มที่ x 331 ± 9 ต่อแถว (noise ความถี่ต่ำ) → เต็มที่ x 400 (L) / 693±9 → 624 (R) กว้าง 60–78 px + noise 2 มิติในเนื้อหมอก, กล่องฉากขยายถึง 404 ให้เนื้อฉากต่อเข้าหมอก (ตัวตรวจขอบแข็ง x 370–400 ยังใช้กล่องเดิม 376), ซองคอลัมน์ที่ขาดตรงในแถบขอบ x ≥ 300 ไล่จาง 16 px แทนตัดตรง; แนวดิ่ง y 300→1360 (ขอบบนนุ่ม 40 px, ล่างหยุดที่ขอบคลื่นจริง) — ไม่ใช้เพดาน 0.5 ของ `veil_column` เพราะโซนนี้ถูกรูปถ่ายบังทั้งหมด; เงื่อนไขเดียวที่ทำให้ม่านนี้ถูกต้องคือข้อ 2 (ขอบแข็งของสถานที่อยู่นอก ramp ทั้งหมด) — ให้ `fit-bg` ตรวจเอง: แถว std > 3 ใน x 370–400 (L) หลังย่อ/เลื่อนต้อง ≤ 15% ของแถว 420–1300 มิฉะนั้นถือว่าขอบแข็งยังล้ำ → exit 1
5. darken_band และ `veil_column` ≤ 0.5 ตามเดิม (ใช้เก็บส่วนหัว/ความเรียบที่เหลือ)
เพดานที่ยังสวย: s ≥ 0.70 · shift ≤ 40 · ramp 30 px · แถบบนที่เติมฟ้า ≤ 300 px · ของนุ่มที่ถูกม่านกิน ≤ 45% ความกว้างฉาก (เกินนั้นองค์ประกอบ "ลอย")

### 8.2 ฉาก bottom — ย่อฉากทั้งแถบ uniform แทน shift_down (ฐานต้องถึงแถบคลื่น)
1. ฉาก = แถบเต็มกว้าง y จาก `landmark_top − 40` ถึง 1536 · ย่อ uniform ยึดกลางล่าง (512, 1536): `s = (1380 − 908) / (1380 − landmark_top)` clamp **0.68 ≤ s ≤ 1**
2. ช่องข้าง 2 ฝั่ง กว้าง `512·(1−s)` (เพดาน **≤ 170 px**): เติมด้วย **mirror-extend** ของขอบฉากที่ย่อ (ใบไม้/ต้นไม้ชายขอบ) ขนนุ่ม 40 px ที่รอยต่อ — ใช้ได้เพราะริมภาพทั้ง 3 ภาพเป็นพุ่มไม้ ไม่ใช่สิ่งก่อสร้าง
3. ช่องบนที่โผล่: ลบยอดเดิมด้วยไล่สีฟ้าต่อจากแถว `landmark_top − 60` (ใช้ slope จาก 120 px เหนือขึ้นไป) ขนนุ่ม 80 px ก่อนวางฉาก
4. แปะกลับของเดิม: แถบคลื่น y ≥ 90% เต็มกว้าง + **กล่องดอกไม้มุมล่าง** x < 260 / x > 764, y > 1250 (ขนนุ่ม 40 px) — ฉากกลาง (ฐานสถานที่) ไม่ถูกทับ
5. เศษที่ยังขาดหลัง s ถึง 0.68: ใช้ `shift_down` ได้ **≤ 40** โดยฐานล่างสุด (บันไดชั้นล่าง/ลาน) จมใต้ขอบคลื่น **≤ 24 px** เท่านั้น — เกินกว่านี้ยอมไม่ได้ (สถานที่ผิดรูป) → สร้างใหม่
6. ยืดฟ้า (shift_down เดิม) ยังใช้ได้เมื่อ `landmark_top` ขาด ≤ 60 และฐานเดิมอยู่สูงกว่าขอบคลื่น ≥ ระยะที่เลื่อน (ฐานไม่จม) — np-19 แบบไม่ย่อเข้าข่าย (ขาด 122 แต่ฐาน 1314 จะจม 56 → ไม่เข้า ให้ย่อแทน)
7. veil.auto ยอมถึง 0.8 ได้ (ฟ้าตามแบบคือฟ้าซีดอยู่แล้ว) + darken_band เดิม
