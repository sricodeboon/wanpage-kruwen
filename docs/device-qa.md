# Device QA — ก่อนปล่อย และทุกครั้งที่แก้ render/share

## เครื่องที่ต้องทดสอบ
- [ ] Android Chrome (Samsung กลาง)
- [ ] Android Chrome (Xiaomi/OPPO RAM ≤ 3 GB)
- [ ] Samsung Internet
- [ ] iPhone Safari (iOS 16+)
- [ ] LINE in-app browser (Android)
- [ ] LINE in-app browser (iOS)
- [ ] Slow 4G throttling
- [ ] โหมดเครื่องบินกลางทาง

## ต้องผ่าน (spec 13.4)
- [ ] เปิดครั้งแรก ≤ 3 วิ จนเลือกได้; ครั้งถัดไป ≤ 1.5 วิ
- [ ] รูปไม่กลับหัว
- [ ] กดรายงาน → พรีวิว ≤ 3 วิ
- [ ] ตัวหนังสือไทยถูกต้องทั้ง 30 ภาพ
- [ ] กล่องไม่ทับจุดเด่นของพื้นหลัง
- [ ] แชร์เข้ากลุ่มได้ไฟล์ PNG 1 ครั้ง ไม่ซ้ำ
- [ ] ยกเลิกแชร์ไม่พัง
- [ ] ปิดเน็ตก่อนแชร์ → บันทึกรูปได้; เปิดเน็ตแล้วเปิดแอป → Drive ได้ 1 ไฟล์ + log 1 แถว
- [ ] Apps Script ช้า 60 วิ (`Utilities.sleep`) → UI ไม่รู้สึกช้า
- [ ] ส่งซ้ำวันเดียวกัน → 2 ไฟล์ชื่อต่างกัน
- [ ] ปิด Apps Script ทั้งตัว → ยังแชร์ได้ + สถานะชัดเจน
- [ ] ทดสอบกับครูเวรจริง 2 คน (Android + iPhone) โดยไม่สอน จดจุดลังเล
- [ ] รวม ≤ 90 วิ แตะ ≤ 15 ครั้ง
- [ ] หน่วยความจำสูงสุดของแท็บ ≤ 250 MB (Android RAM ต่ำ เลือก 12 MP 4 รูปติดกันไม่ค้าง)

## เช็กที่เลื่อนมาจากการพัฒนา (ต้องทำบนเครื่องจริง)
- [ ] ภาพที่มี EXIF หมุน (ถ่ายแนวตั้ง/หมุน 4 ทิศ) แสดงตั้งตรงในพรีวิวและภาพสุดท้าย
- [ ] ลำดับ resize + orientation ถูกต้อง (ไม่หมุนซ้ำ/ไม่บีบสัดส่วนผิด) ทั้งภาพ 12 MP
- [ ] พื้นที่แตะ label (เปลี่ยนป้ายรูป) กับการแตะช่องรูป (เลือกรูป) ไม่ชนกันในช่องรูปขนาดเล็ก
- [ ] share sheet: เปิดได้และส่งไฟล์ PNG ได้ทั้ง "ใน LINE in-app" และ "นอก LINE" (เบราว์เซอร์ปกติ)
- [ ] ออฟไลน์ถ่ายรายงาน → ต่อเน็ตภายหลัง → อัปโหลดขึ้น Drive สำเร็จ 1 ครั้ง (ไม่ซ้ำ)
